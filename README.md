

## Aplicacion web con 5 paginas (inicio + 4 adicionales) hecha con Flask, HTML y CSS.

## Estructura
```
proyecto/
  app.py
  templates/
    index.html
    pagina1.html
    pagina2.html
    pagina3.html
    pagina4.html
    saludo.html
  static/
    estilos.css
    img/
```

## Como ejecutar


1. Ejecutar el servidor:

python app.py

3. Abrir en el navegador:

http://localhost:5000


## Nota sobre debug=True

El servidor se ejecuta con `debug=True`, lo cual recarga automatica y mensajes de error detallados.
